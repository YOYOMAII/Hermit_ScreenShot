HermitScreenshot — what to send friends
======================================

ONE LINK FOR EVERYONE:
  https://github.com/YOYOMAII/HermitScreenshot/releases/latest

Mac friend:
  Download HermitScreenshot-Mac.zip
  Unzip → right-click HermitScreenshot.app → Open → Open (first time)

Windows friend:
  Download HermitScreenshot-Windows.zip
  Unzip → double-click HermitScreenshot.exe
  First time: More info → Run anyway

Guide is inside each zip (GETTING-STARTED.md).
More copy-paste text: SHARE-WITH-FRIENDS.md in the repo.

You do NOT send:
  - The whole GitHub repo / source code
  - .venv, build/, dist/, code_screenshots/, smart_documents/

New release for friends:
  git tag vX.Y.Z && git push origin vX.Y.Z
  (GitHub Actions builds both zips automatically)
