# Share HermitScreenshot with friends

Send **one link**. Friends pick Mac or Windows — no Python, no GitHub account needed.

## Link to send

**https://github.com/YOYOMAII/Hermit_ScreenShot/releases/latest**

---

## Copy-paste message (Mac friend)

```
HermitScreenshot — code screenshots for assignments

Download: https://github.com/YOYOMAII/Hermit_ScreenShot/releases/latest
→ HermitScreenshot-Mac.zip

1. Unzip
2. Right-click HermitScreenshot.app → Open → Open (first time only)
3. Drop your .html / .css files, generate PNGs
4. HermitSmart tab = put screenshots into Word

Runs only on your Mac. Files stay on your computer.
```

---

## Copy-paste message (Windows friend)

```
HermitScreenshot — code screenshots for assignments

Download: https://github.com/YOYOMAII/Hermit_ScreenShot/releases/latest
→ HermitScreenshot-Windows.zip

1. Unzip
2. Double-click HermitScreenshot.exe
3. If Windows warns you: More info → Run anyway (first time)
4. Drop your .html / .css files, generate PNGs
5. HermitSmart tab = put screenshots into Word

Runs only on your PC. Files stay on your computer.
```
